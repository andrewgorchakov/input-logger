# Проект InputLogger

Логгер ввода для игровых/девелоперских задач: фиксирует нажатия клавиш, движения мыши, тайминги и воспроизводит события.
Подходит для анализа пользовательского ввода, отладки игровых механик, создания демо/реплеев.

## Используемые технологии

- Java 8
- LWJGL + GLFW
- Maven
- Jackson

## Запуск

Для запуска иметь в локальной папке запуска нативную библиотеку lwjgl, её необходимо прописать в pom.xml в разделе properties.

Для запуска на MacOS необходимо указать ключ запуска VM options -XstartOnFirstThread

Класс ParallelLogger отвечает за запись, а VisualPlayer за воспроизведение событий.

## Структура классов

InputEventsLog - класс, описывающий структуру для хранения лога.

ParallelLogger - класс, отвечающий за запись.

TimelineEvent - класс, описывающий структуру данных для хранения события в таймлайне.

VisualPlayer - класс, отвечающий за воспроизведение.
